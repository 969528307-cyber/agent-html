Three community-curated awesome-lists have emerged as the primary discovery layers for their respective agent ecosystems.

## OpenClaw: 162 Templates and Counting

The `awesome-openclaw-agents` repository now hosts 162 production-ready AI agent templates across 19 categories. Each template is a SOUL.md configuration file that defines agent behavior, tools, and workflows. The community submission model means this number grows weekly.

## Claude Code: The 44K-Star Hub

`awesome-claude-code` has reached 44,210 stars, consolidating skills, hooks, slash-commands, agent orchestrators, and plugins for Claude Code. Its scale signals that the Claude Code developer ecosystem is the largest among individual agent platforms.

## Skills Get Their Own List

`awesome-agent-skills` (4,902★) fills a gap: a dedicated index for agent skills, separate from general MCP server or framework lists. This reflects the growing recognition that Skills are a first-class extension type, not a subset of MCP.

## The Discovery Stack

These awesome-lists complement 2playclaw.com's directory. We index individual tools with verified metadata; awesome-lists curate collections with community context. Together: find the tool on 2playclaw.com, explore the ecosystem on the awesome-list.
