Two GitHub projects this week highlight the parallel development of China's AI agent infrastructure.

## agentUniverse: Chinese Multi-Agent Framework

agentUniverse is a multi-agent framework that allows developers to build collaborative LLM applications. At 2,241 stars, it represents a growing category of Chinese-origin agent frameworks that serve the domestic developer ecosystem with Chinese-language documentation and use cases.

## indie-hacker-tools-plus: Chinese Developer Stack

This curated collection focuses on tools for independent Chinese developers, with an emphasis on practical, market-proven tools that reduce costs and improve efficiency. It includes AI agent tools alongside broader development infrastructure.

## The Parallel Ecosystem Pattern

The Chinese AI agent ecosystem is not simply translating global tools. It's building its own frameworks (agentUniverse), its own agent platforms (Kimi, Trae, Qwen Code), and its own discovery layers. For global users, understanding this parallel development is key to evaluating which tools work across ecosystems and which are region-specific.
