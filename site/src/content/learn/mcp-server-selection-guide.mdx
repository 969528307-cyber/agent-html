## License Distribution

Apache-2.0 and MIT are the most common licenses, accounting for over 70% of all tools. Always check the specific repository's LICENSE file before use.

## Selection Advice

- Need document lookup: Start with Context7 (55K★) or MCP Toolbox
- Need database access: PostgreSQL MCP Server, MongoDB MCP Server are verified and available
- Need DevOps integration: Kubernetes MCP Server, Docker MCP Server, Terraform MCP Server
- Need browser automation: Chrome DevTools MCP (40K★) or Playwright MCP
